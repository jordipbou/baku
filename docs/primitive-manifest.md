# Baku primitive manifest

Generated by `tools/manifest.py` from the pinned Shen 43.2
kernel. Do not edit; run `python3 tools/manifest.py --write`
after a kernel or primitive-source change.

Corpus: `vendor/shen-43.2/klambda`, 23 files, 1124 top-level
forms (1118 `defun` forms and 6 copyright strings), 1117
distinct `defun` names.

Filtering: a naive scan of every list head yields 2028
distinct heads, 1094 of them not defined by `defun`.
The semantic scan walks application positions only, so
binding lists, `let` variables, `lambda`/`defun` parameter
lists and `cond` clauses are not applications. It yields 1072
applied heads: 934 are kernel `defun` names, 97 are local
`V...`/`W...` variable heads and 41 are host symbols. Every
host symbol is classified below. An unclassified applied
symbol, or a registered primitive the corpus never applies,
fails generation.

primitive is implemented on Baku's value layer and no ANS
word applies. The mapping is generated from the same data that
validates it: a host symbol without a row, a row without an
application, or a row naming a `defun`-defined function fails
generation.
